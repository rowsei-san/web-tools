## 🎬 収録ツール一覧

### Chat AI Video Generator
* **概要**: チャットAI（ChatGPT / Copilot / Gemini 風）の対話アニメーション画面をリアルタイムに生成し、動画（MP4 / WebM）としてキャプチャ保存できるWebツールです。
* **特徴**:
  * 16:9（横型・YouTube向け）/ 9:16（縦型・Shorts / TikTok / Reels 向け）のアスペクト比切り替え対応
  * UIテーマの切り替え（Copilot / Gemini / ChatGPT 風）
  * 人間のタイピング揺らぎ・思考時間・回答スピードなどの細かなパラメータ設定
  * ブラウザだけで即時動画ファイル（MP4 / WebM）を出力可能
* **URL**: [Chat AI Video Generator を起動](https://rowsei-san.github.io/web-tools/chatAI_generator/chatAI_image_gen.html)
