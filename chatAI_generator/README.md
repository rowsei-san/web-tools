## 日本語

主要な大手チャットAI風の対話アニメーション画面をブラウザ上でリアルタイム生成し、動画（MP4 / WebM）としてキャプチャ・保存できるWebツールです。

> ⚠️ **免責事項**: 本ツールは個人が動画制作支援のために開発した非公式ツールです。実在する特定のAIサービスおよびその運営企業とは一切関係ありません。

### ✨ 主な機能
- **複数のUIテーマ**: 大手チャットAIサービス風のデザインに対応
- **アスペクト比切替**: 横型 16:9 (YouTube/PC) / 縦型 9:16 (Shorts/TikTok/Reels)
- **タイピング・思考アニメーション**: 入力速度やヒトのタイピングの「揺らぎ」、思考時間を細かく調整可能
- **動画キャプチャ機能**: ブラウザ上で直接 MP4 / WebM 動画としてダウンロード保存可能

### 🚀 使い方
1. `chatAI_image_gen.html` (または `generator.html`) をブラウザで開きます。
2. 質問テキスト・回答テキストを入力し、テーマやアスペクト比を設定します。
3. 「▶ アニメーション再生」でプレビュー、「💾 動画をキャプチャ＆保存」で録画・保存を行います。

## English

A web tool that generates realistic conversational Chat AI animations on HTML5 Canvas and exports them directly as video files (MP4 / WebM).

> ⚠️ **Disclaimer**: This is an unofficial tool created for video generation support. It is not affiliated with or endorsed by any official AI service providers.

### ✨ Features
- **Multiple UI Themes**: Inspired by popular Chat AI interfaces
- **Aspect Ratio Switching**: 16:9 Landscape (YouTube/PC) & 9:16 Portrait (Shorts/TikTok/Reels)
- **Customizable Dynamics**: Adjust typing speed, human-like typing jitter, and AI thinking delay
- **Direct Video Export**: Capture and download animations directly as MP4 / WebM files

### 🚀 How to Use
1. Open `chatAI_image_gen.html` (or `generator.html`) in any modern web browser.
2. Enter the prompt and answer text, then select your preferred theme and aspect ratio.
3. Click **"▶ アニメーション再生"** to preview, or **"💾 動画をキャプチャ＆保存"** to record and save the video.
